Editor v0.2.0 expands the app into dedicated Edit, Color, and Audio workspaces, adds a configurable export destination panel, and refreshes the interface and app icon in black and yellow.

The screenshots show the Coastal Drift stock-media demo, using footage by [Engin Akyurt on Pexels](https://www.pexels.com/video/aerial-shot-of-an-ocean-9319200/) under the [Pexels License](https://www.pexels.com/license/).

## Edit your way

- Move, group, split, resize, maximize, and float panels inside the editor window. Save named layouts or use Editing, Captions, Effects, and Timeline presets.
- Titles, Captions, Effects, and Transitions each have one dedicated panel. Duplicate entries have been removed from the Project sidebar.
- Create titles from eight styles and customize typography, backgrounds, outlines, shadows, and animation.
- Edit caption text and timing, split and merge cues, import SRT/VTT/ASS, and export SRT/VTT sidecars.
- Apply searchable creative effects to clips or adjustment layers, reorder the effect stack, and add visual dissolves, dips, wipes, iris, and zoom transitions.

![Edit workspace](https://raw.githubusercontent.com/koughen/Editor/v0.2.0/docs/screenshots/edit-workspace.png)

## Grade in the Color workspace

Serial grading nodes, primary/log wheels, RGB bars, custom and secondary curves, RGB mixing, qualifiers, windows, 3D LUTs, keyframes, Gallery stills, reference wipes, bypass controls, and five viewer scopes.

![Color workspace](https://raw.githubusercontent.com/koughen/Editor/v0.2.0/docs/screenshots/color-workspace.png)

## Mix and deliver audio

Track and bus mixing, EQ, compression, reverb, delay, noise suppression, gate/expander, de-essing, ducking, routing, automation, fades, and loudness measurement. Export stereo WAVs and timeline-aligned stems. On macOS, installed effect Audio Units can be used through rendered previews and exports.

![Audio workspace](https://raw.githubusercontent.com/koughen/Editor/v0.2.0/docs/screenshots/audio-workspace.png)

## Export and continue in another app

Control resolution, frame rate, codec, bitrate, scaling, audio settings, and export range. Create handoff packages for Premiere Pro, DaVinci Resolve, After Effects, or CapCut, choosing editable clips or a rendered appearance transfer.

![Export workspace](https://raw.githubusercontent.com/koughen/Editor/v0.2.0/docs/screenshots/export-workspace.png)

## Validation and scope

- TypeScript checking and production frontend build; native macOS build and workspace interaction checks.
- 37 Rust tests across editing, GPU effects, audio, and export passed, along with focused WASM, caption, text appearance, and docking checks.
- The wider JavaScript suite passed 188 tests and has three existing failures in text-mask snapping, custom-mask point insertion, and fractional placement fixtures; these are documented in the workspace notes.
- Floating panels stay inside the app window. Transitions here are visual; audio fades live in Audio. Native plug-in hosting currently supports macOS Audio Units through offline rendering.
- Handoffs use interchange formats and include transfer notes. Effects can be baked with Preserve appearance; equivalent native effect controls are not recreated in every destination. CapCut draft transfer is experimental.
