# Screenshot media credits

The Edit, Color, Audio, and Export screenshots were captured from the native app using a separate **Coastal Drift — Stock Demo** project.

The stock footage is [Aerial Shot of an Ocean](https://www.pexels.com/video/aerial-shot-of-an-ocean-9319200/) by **Engin Akyurt**, supplied by Pexels under the [Pexels License](https://www.pexels.com/license/). Source and license were checked on September 18, 2026.

The demo uses a 12-second excerpt resized to 1920 × 1012, with a title added in the editor. The Color screenshot shows a two-node grade and the viewer waveform. The source clip is silent; the Audio screenshot demonstrates the workspace controls while stopped.

The repository contains screenshots of the editor, not a redistribution of the standalone stock video. The original clip was downloaded locally to create the demo. The source creator and Pexels do not endorse this project.

`assets/screenshot-editor.png` is a copy of the current Edit workspace screenshot for older links. Documentation and release notes use the four screenshots in this directory.
